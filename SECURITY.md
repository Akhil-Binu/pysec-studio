# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We prioritize the security and integrity of PySecStudio and the automated scripts it produces.

If you identify a security vulnerability in this project:

1. **Do Not File a Public Issue**: Please refrain from opening a public issue or discussion thread for unpatched vulnerabilities.
2. **Submit Privately**: Use GitHub's private vulnerability reporting feature under the **Security** tab of this repository, or email the project maintainer directly.
3. **Include Details**:
   - Detailed description of the vulnerability and potential impact.
   - Clear steps or proof-of-concept to reproduce the behavior safely.
   - Recommended mitigations or patches if available.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
